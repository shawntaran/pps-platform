# Placement Training V1

Interactive prototype for the PPS4027 placement-training platform. It uses mock API data so the dashboard can be developed independently from the ATS engine.

## What is included

- Student dashboard: content library, calendar, CA1/CA2/CA3 assignments and reminders
- Resume-review flow: PDF/DOCX upload, JD input, consent, and structured ATS report
- Trainer dashboard: assigned student submissions, scores, progress and review comments
- Admin console: user/role list, scoring configuration and compliance audit view
- RBAC guards on every protected screen and mock API action

## Demo accounts

Use the sidebar account selector to view the student, trainer and admin experiences.
